Transparan & Profesional

Alur Kerja & Ketentuan Layanan

Aturan main yang jelas supaya pengurus nyaman, anggaran aman, dan website rilis tepat waktu sesuai jadwal proker kalian.

1. Sistem Pembayaran Aman (DP 50%)

DP (Down Payment) 50% dibayarkan di awal setelah kesepakatan konsep desain, dan pelunasan 50% dibayarkan setelah website selesai dikerjakan dan siap dipublikasikan secara resmi.

2. Kesiapan Materi Konten (1 Folder Drive)

Teks profil, daftar nama pengurus, logo organisasi, dan foto kegiatan disediakan oleh pihak organisasi dalam satu folder Google Drive. Untuk paket Dinamis, kami sediakan panduan singkat cara input mandiri.

3. Batas Revisi Desain (Maks. 3x Minor)

Gratis maksimal 3x revisi minor (perubahan palet warna, tata letak teks, atau pergantian gambar) selama masa pengerjaan sebelum web rilis. Perombakan struktur halaman total di luar kesepakatan awal dikenakan biaya tambahan.

4. Estimasi Waktu Pengerjaan Cepat

Pengerjaan membutuhkan waktu 3–5 hari kerja untuk Paket Web Statis, dan 7–14 hari kerja untuk Paket Web Dinamis (terhitung sejak pembayaran DP dan materi konten awal diterima lengkap).

5. Aturan Update Konten Berkala (Khusus Paket Web Statis)

  • • Gratis 1x Update Konten Pertama: Berlaku kapan saja di tahun pertama setelah website resmi dirilis.
  • • Layanan Update Berkala (Rp25.000 / sesi): Direkomendasikan setiap 3 bulan sekali untuk memperbarui galeri foto kegiatan (maks. 10 foto), daftar prestasi terbaru, teks informasi, atau tautan pendaftaran tanpa mengubah desain halaman.
  • • Sistem Single-Batch: Seluruh materi pembaruan pada satu sesi update wajib dikirimkan sekaligus dalam satu folder Google Drive (tidak dicicil terpisah-pisah).
